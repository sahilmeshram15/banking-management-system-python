# Banking Management System

A simple Banking Management System developed using Basic Python.

## Features

* Create Account
* View Account
* Deposit Money
* Withdraw Money
* Check Balance
* Transfer Money
* Search Account
* Transaction History

## Technologies Used

* Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in terminal.
4. Run:

python banking_system.py
