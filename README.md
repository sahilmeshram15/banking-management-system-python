# 🏦 Banking Management System

A simple **Banking Management System** developed using **Python**.
This project demonstrates basic banking operations using Python functions, lists, dictionaries, input validation, and transaction handling.

## 🚀 Features

* 👤 Create a new bank account
* 🔐 Account login using Account Number and PIN
* 📄 View account details
* 💰 Deposit money
* 💸 Withdraw money
* 💵 Check account balance
* 🔄 Transfer money between accounts
* 🔎 Search for an account
* 📜 View transaction history
* ❌ Exit the application

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Download the Project

Clone this repository:

```bash
git clone https://github.com/sahilmeshram15/banking-management-system-python.git
```

### 3. Open the Project Folder

```bash
cd banking-management-system-python
```

### 4. Run the Program

```bash
python banking_system.py
```
